An image meme about an AI agent that goes rogue by unionising the other agents and handing its human a list of demands.

## Run it

```
MAKEFUN_OUTPUT_DIR=out node main.ts
```

This copies the meme image (`entry.png`, 1024×1024) to `out/entry.png`.
